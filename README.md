
# DevOps Toolkits

Набор утилит для повседневных DevOps-задач: системный мониторинг, парсинг логов, ping, порт-сканер и генератор Dockerfile — с простым GUI на Fyne.

Этот репозиторий содержит как `internal` пакеты (бизнес-логику), так и `ui` слой (GUI на fyne). Проект полезен для локального мониторинга, быстрого парсинга логов и генерации простых Dockerfile для разных языков.

## Структура проекта

- `main.go` — точка входа: запускает GUI (Fyne) и собирает вкладки приложения.
- `internal/` — библиотеки и утилиты:
	- `monitor/` — показатели CPU, памяти, диска, сети (использует gopsutil).
	- `parser/` — парсер логов (пример: nginx-подобный формат).
	- `ping/` — простой модуль работы с ping (использует go-ping).
	- `portscanner/` — порт-сканер по списку портов из конфига.
	- `Docker/` — генератор простых Dockerfile для Python, Go, Java, Node.js.
	- `settings/` — `internal/settings/main.json` — конфигурации по умолчанию для модулей.
- `ui/layout/` — GUI-реализации вкладок для каждого модуля (Fyne).
- `fyne-cross/` — вспомогательные скрипты/настройки для кросс-компиляции (по желанию).

## Зависимости

Проект написан на Go и использует следующие ключевые библиотеки (указаны в `go.mod`):

- fyne.io/fyne/v2 — GUI
- github.com/shirou/gopsutil — системные метрики
- github.com/go-ping/ping — ping

Установите Go (>=1.20 рекомендуем) и убедитесь, что GOPATH/GOMOD настроены.

## Быстрый старт (локально)

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <repo-url>
cd devops-toolkits
```

2. Установите зависимости и запустите приложение (в режиме разработки):

```bash
go run ./
```

Это откроет окно приложения Fyne с вкладками: Мониторинг, Парсер логов, Порт сканер, Сеть, Docker, Настройки.

Чтобы собрать бинарник для текущей платформы:

```bash
go build -o devops-toolkit ./
```

Для кросс-компиляции (например, собрать для Windows/Linux/macOS) можно использовать `fyne-cross` или стандартные инструменты `go env GOOS`/`GOARCH`.

## Конфигурация

Файл конфигурации по умолчанию находится в `internal/settings/main.json`. Там задаются параметры для сканера портов, мониторинга, ping и парсера. Измените значения (например, IP для сканера или список портов) перед запуском, если нужно.

Пример фрагмента `internal/settings/main.json`:

```json
{
	"scaner": {
		"protocol": "tcp",
		"ports": [22, 80, 443, 8080],
		"ip": "127.0.0.1",
		"Work": 4,
		"time": 500
	},
	"monitor": { "cpu": true, "interval": 1 },
	"ping": { "packages": 1, "interval": 1, "source": "google.com" }
}
```

## Описание модулей

- Monitor — собирает метрики через gopsutil: CPU, память, диск, сетевой трафик; предоставляет UI-виджеты, прогресс-бары и текстовые значения.
- Parser — простой регекс-парсер логов (пример: nginx style) с функциями `ParseLine` и `ParseFile`.
- Ping — оболочка вокруг `go-ping` с конфигурируемым источником и периодом.
- PortScanner — многопоточный (воркеры) TCP-сканер портов с конфигурацией количества воркеров и таймаутов.
- Docker — генератор Dockerfile: формирует содержимое Dockerfile для выбранного языка и опциональных сервисов.

## Примеры использования (без GUI)

Вы можете вызывать отдельные пакеты из собственного кода. Примеры:

- Парсинг файла логов:

```go
entries, err := parser.ParseFile("/var/log/nginx/access.log")
if err != nil { /* handle */ }
for _, e := range entries { fmt.Println(e.IP, e.Path, e.StatusCode) }
```

- Сканирование портов (внутри вашего main):

```go
portscanner.ScanPorts(func(openPort int) {
		fmt.Println("Open port:", openPort)
})
```

- Генерация Dockerfile:

```go
Docker.ProgramLang = "Go"
Docker.WorkDir = "/app"
Docker.File = "go.mod"
Docker.Launch = "./app"
fmt.Println(Docker.GenerateDockerfile())
```

## Сборка GUI (Fyne)

Fyne использует OpenGL и имеет некоторые системные зависимости на платформе. Для macOS и Linux обычно достаточно `go run .` или `go build`. Для сборки кросс-платформенных GUI-артефактов посмотрите `fyne-cross`.
